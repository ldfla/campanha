## Tarefas concluídas e arquivos alterados

### P04-01: Cadastro com WhatsApp como identificador (parcial)
- `AuthController.java` — POST /auth/register, /auth/login, /auth/logout, GET /auth/me
- `AuthService.java` — registro, login, normalização de telefone (+55 default), construção de AppUserDetails
- `RegisterRequest.java`, `LoginRequest.java`, `UserResponse.java` — DTOs com validação Jakarta
- **Pendente:** verificação por token SMS/WhatsApp (Twilio) — requer credenciais externas

### P04-02: Sessões seguras
- `SecurityConfig.java` — Spring Security 7.x, HttpSessionSecurityContextRepository, CookieCsrfTokenRepository
- `V007__spring_session_tables.sql` — migração Flyway para Spring Session JDBC
- Cookies HttpOnly/Secure/SameSite, máximo 3 sessões concorrentes
- CSRF excluído para endpoints de auth (register, login, logout)

### P04-05: RBAC básico
- `AppUserDetails.java` — implementa UserDetails, mapeia papéis para GrantedAuthority ROLE_*
- 10 papéis: VISITOR, PARTICIPANT, PROMOTER, SUPPORT, CAMPAIGN_MANAGER, FINANCE, COMPLIANCE_REVIEWER, DRAW_AUDITOR, SECURITY_ADMIN, SYSTEM_ADMIN
- `/admin/**` requer SYSTEM_ADMIN ou SECURITY_ADMIN
- Participante padrão quando sem memberships

### P04-08: Testes
- `AuthControllerTest.java` — 9 testes (registro, duplicata, validação, login, logout, anti-enumeração)
- `RbacTest.java` — 5 testes (admin bloqueado, não autenticado, health público, perfil, logout)
- `AppUserDetailsTest.java` — 4 testes (authorities, isAdmin, hasRole)
- `MoneyTest.java` — 9 testes (ofCents, ofReais, add, subtract, negativo, display, zero, greaterThan)

### Infraestrutura de segurança
- `GlobalExceptionHandler.java` — mapeia BusinessException e validation errors para RFC 7807
- `RateLimitFilter.java` — rate limiting por IP em /auth/login e /auth/register (10 req/60s)
- `ErrorCode.java` — adicionado AUTH_DUPLICATE_CREDENTIAL, BusinessException, toException()
- `Money.java` — corrigido subtract() para lançar ArithmeticException em resultado negativo

### Entidades JPA
- `User.java` — mapeamento para tabela users, versionamento otimista
- `Organization.java` — mapeamento para tabela organizations
- `Membership.java` — mapeamento para tabela memberships, liga User a Organization com UserRole
- `UserRepository.java`, `MembershipRepository.java` — repositórios tipados

## Riscos, limitações e bloqueios
- Verificação por SMS/WhatsApp (Twilio) pendente — credenciais externas necessárias
- WebAuthn/passkeys (P04-03) pendente — Spring Security 7.x suporta, mas requer setup adicional
- MFA para admins (P04-04) pendente
- CRUD de usuários/membros (P04-06) pendente
- Rate limiter usa ConcurrentHashMap em memória — adequado para instância única
